JSON Output Converter

키워드 텍스트 → themes용 JSON 변환기

정리해둔 텍스트를 붙여넣으면 themes 배열에 바로 넣을 수 있는 JSON 객체 또는 keywordPools만 분리된 JSON으로 변환합니다.

기본 정보

theme 객체에 들어갈 이름, id, 추천 장르/BPM을 같이 설정할 수 있어요.

비워두면 영어명을 기준으로 자동 생성
예: [ { "genreId": "dream_pop", "weight": 4, "reason": "몽환적인 기억 표현에 적합" } ]
예: [ { "bpmId": "slow_mid_76_90", "weight": 5, "reason": "회상 특유의 느린 흐름에 적합" } ]
