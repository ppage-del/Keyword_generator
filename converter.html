추첨기로 돌아가기 키워드 → JSON 변환기

Keyword to JSON Converter

키워드 텍스트 → JSON 출력 변환기

대주제 버튼을 누르면 이름/id가 자동 입력되고, 감정/이미지/행동/시공간/영어 키워드 블록에 텍스트를 붙여넣으면 JSON을 만들어줍니다.

1. 대주제 선택

버튼을 누르면 대주제 한글명, 영어명, id가 자동 입력됩니다.

비워두면 영어명을 기준으로 자동 생성됩니다.

2. 카테고리별 직접 입력

쉼표, 줄바꿈, 중복, 불릿, 번호가 섞여 있어도 알아서 정리합니다.

예: 감정만 출력하고 싶을 때 사용

3. 원본 텍스트 자동 분배

한 덩어리 원문을 붙여넣고 자동으로 각 블록에 나눠 담을 수도 있습니다.

  • 쉼표(,)와 줄바꿈을 모두 구분자로 인식합니다.
  • 중복 항목은 자동 제거합니다.
  • 맨 앞의 숫자, 불릿(-, •) 같은 표시는 자동 정리합니다.
