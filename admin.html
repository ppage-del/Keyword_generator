ADMIN PANEL

데이터 입력 관리자

대주제를 선택하고 키워드만 입력하면, 테마 JSON 또는 전체 data.json을 자동 생성합니다.

추첨 페이지

1. 대주제 선택

버튼을 누르면 id / 한글명 / 영문명 / 추천 장르 / 추천 BPM이 자동 입력됩니다.

2. 카테고리별 입력

줄바꿈 또는 쉼표로 입력해도 자동 정리됩니다.

3. 원본 텍스트 자동 분배

감정 / 이미지 / 행동 / 시공간 / 영어 같은 헤더가 있으면 자동으로 각 칸에 분배합니다.

4. 미리보기

입력 개수, 추천값, 생성될 JSON을 바로 확인할 수 있습니다.

입력 현황

추천값 미리보기

5. JSON 생성 / 복사 / 다운로드

현재 테마 JSON, keywordPools만, 전체 data.json 병합본을 생성할 수 있습니다.
